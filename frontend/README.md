# Intrusion Detection Dashboard - React Frontend

This directory will contain the React frontend dashboard for real-time network flow monitoring, threat analysis visualization, model predictions, and XAI insights.

## Planned Features
- **Real-Time Alert Feed**: Display live network traffic classification results and severe threat alerts.
- **Threat Severity Matrix**: Visual distinction between Model Confidence (%) and Threat Severity (Low/Medium/High/Critical).
- **SHAP Explanation Dashboard**: Interactive visual breakdown of flow features contributing to a threat detection.
- **Model Analytics**: Performance metrics overview, ROC curves, and confusion matrix views.

## Tech Stack
- React / Vite
- Modern Vanilla CSS Design Tokens & Utilities
- Chart.js / Recharts for live telemetry visualization
