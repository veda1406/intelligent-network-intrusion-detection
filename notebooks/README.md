# Jupyter Notebooks Directory

This directory contains experimental, exploratory, and visual analysis notebooks for the Intelligent Network Intrusion Detection System.

## Notebook Structure & Execution Sequence

1. `01_eda.ipynb`: Exploratory Data Analysis (distribution, missing values, class distributions).
2. `02_preprocessing_experiments.ipynb`: Cleaning, scaling, and class imbalance experiments.
3. `03_baseline_models.ipynb`: Training and evaluating traditional ML baseline models (Logistic Regression, Decision Tree, Random Forest, SVM).
4. `04_dnn_model.ipynb`: TensorFlow/Keras Deep Neural Network training and hyperparameter tuning.
5. `05_ensemble_evaluation.ipynb`: Comparative evaluation of Soft Voting and Stacking ensemble methods against individual models.
6. `06_xai_shap.ipynb`: Explainable AI using SHAP feature importance & threat severity visual analysis.

> **Note:** Reusable code developed during experimentation must be modularized into the `src/` directory.
